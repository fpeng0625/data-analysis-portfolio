### 项目2：校园图书借阅运营数据分析系统
> 软件工程课程设计 | 2025.09 - 2025.12

设计校园图书借阅管理系统的数据库结构，对8500条借阅流水数据进行多维度分析，计算图书流通率和用户活跃度，定位冷门品类和高流失用户，为馆藏优化和用户运营提供数据支撑。

**技术栈**：Python、SQLite、SQL（JOIN/GROUP BY/子查询/CASE WHEN）、Pandas、Matplotlib

**核心成果**：
- 设计3张核心表（用户、图书、借阅流水），通过外键关联
- 发现大一学生借阅量占40.9%，大三仅占14.4%
- 验证二八定律：20%高活跃用户贡献60%借阅量
- 输出2条运营优化建议

### 项目3：智能大棚环境监测数据分析系统
> 数据库课程设计 | 2024.09 - 2024.12

对智能大棚4类传感器（温度、湿度、光照、CO₂）采集的2160条时序数据进行统计分析、异常检测、趋势分析和相关性分析，定位核心环境因子，搭建三级异常预警规则，输出分时段调控方案。

**技术栈**：Python、SQLite、SQL（分组统计/条件筛选/UPDATE）、Pandas、NumPy、Matplotlib、Seaborn

**核心成果**：
- 设计传感器时序表，建立时间索引优化查询
- 两种异常检测方法结合（阈值法+3σ统计法），检测出5%异常数据
- 相关性分析发现温度与光照强正相关（0.8），与湿度负相关（-0.6）
- 定位温度为核心环境因子，搭建三级预警规则
